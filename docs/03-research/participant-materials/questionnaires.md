# Questionnaires

Three instruments. Fill the first two in paper or via a Google Form; transcribe to CSV for analysis.

---

## 1. NASA-TLX (one per condition)

Rate each dimension on a 0–100 scale (in 5-point increments). Each participant fills three copies — one after each block.

| Dimension | Question | 0 (Low) | 100 (High) |
|---|---|---|---|
| Mental Demand | How mentally demanding was this block? | Very low | Very high |
| Physical Demand | How physically demanding was this block? | Very low | Very high |
| Temporal Demand | How hurried or rushed was the pace? | Very low | Very high |
| Performance | How successful were you in detecting hazards? | Perfect | Failure |
| Effort | How hard did you have to work to detect hazards? | Very low | Very high |
| Frustration | How insecure / discouraged / annoyed were you? | Very low | Very high |

Raw TLX score = sum of the 6 sub-scales (range 0–600). We do **not** use the weighted version — too long for a 30-minute session.

---

## 2. SUS — System Usability Scale (one total, end of session)

Asked about the alert system as a whole (combining standard + AR conditions).

Rate 1 (strongly disagree) → 5 (strongly agree).

1. I think that I would like to use this system frequently.
2. I found the system unnecessarily complex.
3. I thought the system was easy to use.
4. I think that I would need the support of a technical person to be able to use this system.
5. I found the various functions in this system were well integrated.
6. I thought there was too much inconsistency in this system.
7. I would imagine that most people would learn to use this system very quickly.
8. I found the system very cumbersome to use.
9. I felt very confident using the system.
10. I needed to learn a lot of things before I could get going with this system.

**Scoring:** For odd items: subtract 1 from the response. For even items: subtract response from 5. Sum × 2.5 = SUS score (0–100).

## 3. Demographics + free text (one total, end of session)

| # | Question | Format |
|---|---|---|
| 1 | Age | Number |
| 2 | Gender | Open / decline to answer |
| 3 | Do you hold a driving license? | Y / N |
| 4 | If yes, how many years have you had it? | Number |
| 5 | How often do you drive? | Daily / Weekly / Monthly / Rarely / Never |
| 6 | Have you ever used a dashcam or driver-assistance system (lane-keep, AEB, etc.)? | Y / N — if Y, which? |
| 7 | Did you find the alert sound distracting? | 1 (not at all) – 5 (very) |
| 8 | Did you find the AR overlay helpful? | 1 (not at all) – 5 (very) |
| 9 | Did you trust the system's alerts? | 1 (not at all) – 5 (completely) |
| 10 | Anything else you'd like to share about the experience? | Free text |

## Custom trust item (single Likert)

Could be added to the demographics page or used standalone:

> "I trusted the alert system to tell me when there was a real hazard."

1 (Strongly disagree) – 2 – 3 – 4 – 5 (Strongly agree)
